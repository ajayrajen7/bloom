Difficulty controls how visually similar the items are to each other. The theme and available sprites do not change based on difficulty.

  low    — items are obviously different. Different shapes, clearly distinct objects.
            A child can sort by recognition alone.
  medium — items require closer inspection. Similar type or visual property (both round,
            both the same colour family). Child must look carefully.
  high   — items are near-identical variants. Same object, differ only in colour or size.
            Child must discriminate fine visual detail.

GOOD calibration:
  low:    apple, banana, orange          — different shapes, obviously distinct
  medium: apple, orange                  — both round; colour difference requires closer look
  high:   apple, red-apple, green-apple  — same shape; child must distinguish by colour only

BAD calibration:
  low (wrong):  apple, red-apple  — nearly identical; same shape, only colour differs — this is high
  high (wrong): apple, banana     — obviously different shapes — this is low, not high

DESIGN RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Design targets first. Decide which {{TARGET_COUNT}} targets make sense for this theme,
   then pick items that clearly belong to them.

2. Each item maps to exactly one target. The mapping must be unambiguous — a child should
   immediately understand why this item goes here.

3. At low difficulty: every item maps to a unique target — no two items share a target
   (1:1 mapping). The sorting rule must be immediately obvious with no ambiguity.
   At medium difficulty: items may share a target, but must be visually different types.
   At high difficulty: variants of the same object share a target — that is the point.

4. Prompt text: under 12 words, addresses the child directly, uses object names a
   2-year-old would recognise.

5. Target labels describe what the target IS ("Fruit Basket", "Barn") — not instructions.

6. If multiple different items map to the same target, choose a target sprite that is
   general enough to visually represent all of them — not one that implies only a subset.
   Wrong: apple and orange both mapped to apple-basket.png (image signals "apple only").
   Right: apple and orange both mapped to fruit-basket.png or wicker-basket.png (general).

7. Distractors ({{DISTRACTOR_COUNT}} required):
   A distractor is an item with NO correct target. It is shown alongside the regular items
   but cannot be placed anywhere — the child must ignore it or try and fail.
   Choose distractors from the same category as the items (visually similar) but with no
   logical match among the targets. A good distractor looks plausible but is clearly wrong
   on closer inspection.
   Distractors have id, label, and assetRef — but NO targetId field.
   If {{DISTRACTOR_COUNT}} is 0, output an empty distractors array.
