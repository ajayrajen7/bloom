Difficulty controls how similar the distractors are to the correct item(s).

  low    — distractors are from a different category. Obvious contrast.
            correct = dog → distractors = apple / ball / banana
  medium — distractors are same category, different type. Requires closer attention.
            correct = dog → distractors = cat / duck / cow
  high   — distractors are same type, differ only in one attribute (colour, size).
            correct = red-ball → distractors = blue-ball / yellow-ball / green-ball
